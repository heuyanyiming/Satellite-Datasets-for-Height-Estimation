# Satellite-Datasets-for-Height-Estimation
This dataset contains the processing and segmentation methods for the DFC2019 and Urban 3D Challenge datasets, designed for single-image height estimation.

DFC2019 data form https://ieee-dataport.org/open-access/data-fusion-contest-2019-dfc2019
Urban 3D Challenge data from https://spacenet.ai/the-ussocom-urban-3d-competition/
Crop the image using crop_image.py
